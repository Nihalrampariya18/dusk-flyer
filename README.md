# 🌅 Dusk Flyer

A fun Flappy Bird-style arcade game built with HTML5 Canvas and vanilla JavaScript.

## 🎮 Live Demo

👉 https://nihalrampariya18.github.io/dusk-flyer/

## ✨ Features

- 🐦 Bird flap physics and gravity
- 🚧 Randomly generated pipes
- 💥 Collision detection
- 🏆 Score and best-score tracking
- 📈 Increasing difficulty
- 🔊 Sound effects with mute option
- 🔄 Game-over and restart system
- 🖱️ Mouse and touch controls
- ⌨️ Spacebar controls
- 📱 Responsive gameplay

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- Web Audio API
- Local Storage

## 🤖 AI-Assisted Development

Claude was used as an AI coding assistant during the development process.

The project was tested, customized and run locally before being deployed using GitHub Pages.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start playing!

## 🎯 Goal

Fly through the pipes without hitting them and try to achieve the highest score possible.
